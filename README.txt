HYROX iPhone App

Como usar:
1. Publica estes ficheiros num servidor HTTPS (GitHub Pages, Netlify, Vercel, etc.).
2. Abre o endereço no Safari do iPhone.
3. Toca em Partilhar > Adicionar ao ecrã principal.
4. A aplicação passa a abrir como uma app e funciona offline depois da primeira visita.

Funcionalidades:
- Treino do dia automaticamente
- Plano completo por semana
- Detalhes de cada treino
- Marcar sessões como concluídas
- Barra de progresso
- Funciona offline via Service Worker
